Notas y seguridad

  • Back4App · subida de archivos: si el servidor responde error 130 ("File upload by public is disabled"), la aplicación inicia sesión con un usuario de servicio y reintenta la subida de forma automática; no necesitas hacer nada.
  • Back4App · almacenamiento: al eliminar un documento se borra el registro; el archivo puede permanecer en el almacenamiento de Back4App (su borrado definitivo requiere la Master Key desde el dashboard).
  • Gemini: la clave viaja en el código público de GitHub Pages. Recomendación: en Google AI Studio restringe la clave al sitio https://argos4all.github.io y rótala si sospechas fuga; luego actualízala en Configuración sin tocar el código.
  • Gemini: si ves "User location is not supported", la red actual bloquea la API de Google; abre el sitio desde tu navegador y red habituales.
  • Acceso admin: la contraseña se verifica localmente con hash SHA-256; nunca se envía a ningún servidor. Tras 5 intentos fallidos, el acceso se bloquea 60 segundos.
  • Privacidad: los documentos se guardan en Back4App y el historial del chat en este navegador. La aplicación no usa analítica ni rastreo.
